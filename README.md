An invented passport spread for the fictional Republic of Aldermere: a specimen data page facing a page of visas and entry stamps.

- Country: Republic of Aldermere, an island nation with its capital at Port Meridian.
- Holder: Mara Elin Alder, born in Port Meridian on 14 March 1998.
- Built with `passport.html`, rendered to `entry.png`; `main.ts` copies the image to the output directory.

## Run it

Render the HTML with a 1024 × 1024 browser viewport to create `entry.png`. Then run `main.ts` with Node 22; it copies the image to `MAKEFUN_OUTPUT_DIR`, or `/output` by default.
